0xAF-Re Architecture Map

A terminal-first RE agent with a REA-inspired metacognition layer: every tool result is stamped into an evidence ledger (ev_NNN), committed claims live in a host-enforced hypothesis stack (H-NNN), and the planner/executor/researcher seats share one auditable loop.

Terminal-first loop

The REPL is the product surface: prompt queueing, live task expansion, slash commands, and raw shell escapes share one workspace policy.

Metacognition layer (new)

Tool results become ev_NNN ledger records; committed claims become H-NNN hypotheses. A contradiction halves confidence and a rejected root cascades a re-check flag to everything derived from it — host code, not prompt hope. After every tool result an arbitrator pass challenges dangling citations and runtime contradictions on its own.

Composable model seats

Planner, executor, and researcher are independent seats. Each can point at a different provider and model without rebuilding the binary, and results flow back into one shared transcript.

Governed evidence collection

File facts come from scoped local tools. Writes, network, sensitive paths, and destructive commands pass through explicit policy gates before anything executes.
