0xAF-Re 架构总图

终端优先的逆向 agent，带 REA 式元认知层：每个工具结果自动入库为 ev_NNN 证据记录，已提交的判断由宿主强制的假设栈（H-NNN）显式管理； planner / executor / researcher 三席位共享同一份可审计转录。

终端优先的循环

REPL 就是产品表面：提示词排队、任务实时展开、斜杠命令和裸 shell 逃逸共享同一套工作区策略。

元认知层（新增）

工具结果变成 ev_NNN 账本记录，已提交的判断变成 H-NNN 假设。一次矛盾就把置信度减半，否定根假设会级联标记所有派生判断 —— 这是宿主代码，不是 prompt 里的美好愿望。每次工具结果后，仲裁器会自动质询悬空引用与运行时矛盾；/audit 让第二个模型在全新上下文里攻击整张假设栈。

可组合的模型席位

规划器、执行器、研究员是三个独立席位，各自可以指向不同的 provider 和模型，无需重新编译；结果统一回流到同一份共享转录。

有治理的证据采集

文件事实来自限定范围的本地工具；写盘、网络、敏感路径和破坏性命令都要先过显式策略闸门。
