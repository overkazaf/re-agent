0xAF-Re Architecture

逆向 / CTF 双模型 Agent · planner (codex) + executor (claude) · 本地 CLI 驱动 · append-only 会话

双模型分工

  • • planner = codex，负责高敏感逆向分析、可利用性推理、解题策略
  • • executor = claude，负责本地命令执行、文件检查、例行总结
  • • auto 模式按提示词关键词（执行/运行/读取/grep…）落到执行侧
  • • 两者都是 cli-tmux 类型：0xAF-Re 只做编排，工具调用在子 CLI 内完成

计划事件的三种来源

  • • Claude：TaskCreate / TaskUpdate，id 由 tool_use_result 结构化绑定
  • • Codex：plan_update（旧壳）/ todo_list（item 新壳）
  • • 兼容：TodoWrite（本机 2.1.220 已无此工具，保留给其他版本）
  • • 子代理事件按 parent_tool_use_id 过滤，不污染操作者的任务表

安全与可观测

  • • 默认只读：写入 / 网络 / 敏感路径均需显式开关
  • • 每次工具调用前过 ExecutionPolicy，路径越界与危险命令直接拒绝
  • • 会话 append-only 落 JSONL，plan 变更逐条记录、可完整回放
  • • HUD 纯观测层，任何解析或渲染异常都不会让一次 run 失败
